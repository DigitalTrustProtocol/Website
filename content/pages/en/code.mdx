## Contributing

- Specifications live with the code that implements them. Propose changes to a spec in its own repository; this site picks them up when the pinned commit is updated.
- Each rendered page has an **Edit on GitHub** link in its footer.
- The trust model is shared by every product. Changes to it need a conformance case and the owner's approval, so all implementations keep giving the same answer ([conformance](/protocol/conformance)).
- Questions: [attention@trust.dance](mailto:attention@trust.dance).
